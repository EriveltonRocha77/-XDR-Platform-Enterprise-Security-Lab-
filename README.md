# XDR Neo-Platform | Enterprise Security Lab 🛡️

Uma plataforma unificada e completa de **Extended Detection and Response (XDR) e Inteligência Cibernética Operacional**. Desenvolvida a nível tático-militar para rastrear, mitigar e auditar ameaças locais e tráfego intercontinental via engenharia reversa, análise forense estatística e coleta de inteligência em fontes abertas.

## 🚀 Arquitetura do Sistema

O ecossistema não utiliza simulações vazias. A grande maioria das opções na interface aciona algoritmos reais, pesados e estatísticos criados puramente no núcleo da API. A malha é isolada localmente utilizando micro-serviços via roteamento Docker:

- **Frontend Tático (HUD Militar):** Painel gráfico hiper-responsivo construído em CSS e JS puros. Estilizado baseando-se em estética Ciberpunk (Painel CRT, animações de Digitação Assíncrona e Neon Interativo).
- **Backend SIEM:** Data Lake e Roteador Cognitivo Escrito em `Python (FastAPI)`. Orquestra a injeção em massa dos logs e invoca scripts secundários matemáticos.
- **Micro-Operadores Externos:** Módulos que avaliam lógicas brutas paralelamente, acessando bibliotecas AST, YARA pattern-matching nativo via REGEX, entre outros.

## 🛠️ Motores e Ferramentas Embutidas

A plataforma possui 18 arsenais de inteligência operando ao simples toque de um botão da Interface Tática de Controle:

### 1. Análise de Inteligência Base (SIEM)
* **Painel Central (SIEM):** Concentrador de telemetria passiva, intercepta e lista todos os disparos dos outros módulos na rede instantaneamente via tabela inteligente.
* **Analisador Estático (SAST):** Escavador de código-fonte focando achados em credenciais mal ocultas (hardcoded) e injeções desprotegidas no fonte do programador de forma estática pura via interpretadores Python AST.
* **Motor Atacante Dinâmico (DAST):** Simulador de injeções de fuzzer web disparando pacotes sobre o servidor de WAF Shield verificando se ele bloqueia tentativas de HEAD requests indesejados e LFI.
* **Auditoria de Nuvem Estrutural (K8s/IAC):** Validador de configurações para contêineres Docker e YAML buscando pods que exigem rodar em formato ROOT super-poderoso violando as premissas de confiança militar.
* **Correlação de IOC via OSINT Total:** Roteamento ativo direto contra a WAN exterior. Acessa APIS de Georreferenciamento BGP e cruza registros em Listas Negras (Spamhaus ZEN via DNS reverso e Socket Layer) rastreando o grau de segurança global de qualquer IP fornecido.
* **Perito Auxiliar de Segurança via IA (SOC Analyst):** Heurística programada via Regras base que determina ações em nanosegundos alertando banimento imediato e expurgo de IP antes mesmo da intervenção Humana da base central. 

### 2. Contra-Medidas Ativas Extrema Sustentada (Rede EDR)
* **Proteção Em Execução Intramural (RASP Shield):** Abatedor interno à prova das chamadas lógicas de bibliotecas corrompidas do motor python. Ele opera cancelando recursos de "globals() && built-ins" para destruir vetores exploratórios executáveis sem consentimento nativo do script base de hospedagem interna.
* **Caçador de Tráfego de Rede Aprofundado Hexagonal:** Conversor em loop de UnhexLify avaliando os frames da Web em bytes e decodificando estruturas famosas do sub-mundo letal conhecidas universalmente como Buffer Overflows de Heap Spraying Nop Sleds.
* **Inspeção de Vias Primárias e Memória Volátil:** Operação YARA puramente de Pattern Matching rastreando as correntes voláteis da Camada De Ram interna identificando chaves de Segurança assimétricas secretadas via extrações cruas puras do binário volúvel perdido no ambiente desregulado de swap.
* **Detecção De Vias Exfiltradas via Túnel Transversal de Protocolo 53 DNS:** Escudo baseado em Entropia Matemática Logarítmica de Shannon visando travar o vazamento oculto mascarado por meio da tradução para URLS imensas irreais criadas unicamente por criminosos profissionais na internet aberta contra perímetros fechados via VPN.
* **Vigilante Anomalógico Neural em Nós de Endpoint Preditivo:** Sistema vital validando via base Teórica Matemática a correlação dos recursos via métrica Z-SCORE em busca intensa e vigilante diuturnamente sobre Threads espalhados fora da média das estaticidades estatutariamente vitais comportando anomalias da assinatura de Vírus sequestradores letais "RansomS".

### 3. Avaliadores, Mapeadores Críticos em Operações (Lab Criptografia e Ofensiva)
* **Estrutura Grafotécnica Espacial de Domínios Ativos Físicos de Ataque Base Dijkstra (BloodHound Logic):** Mapeamento via DFS rastreando as rotas lógicas cruzando autoritariamente a interligação do AD ativo procurando buracos para elevação de prestígio sem credencial em redes coorporativas e mundos privados virtuais da LAN em trânsito com a WAN de roteador de espinha principal da arquitetura do contratante em teste de penetração de segurança validado no exterior do Bunker emulado pelo usuário de segurança final em cargo no ecossistema central da base virtual de ataque frontal lateral ao projeto operante da base cibernética ativa do time Defensivo da Central.
* **Cripto-Quebra de Espectros Algorítmicos Lúdicos Emulada:** Atacante em formato Dicionário executando simulação real contra SHA && MD5 visando forçar o retorno ao padrão original revelando que todas as biometrias roubadas tornam-se nulas nas mãos dos grupos clandestinos cibermilitares de extermínio virtual da paz armada base lógica do sub-mundo cibernético criminoso em redes anônimas do submundo tático criptocriminoso do mundo em guerra tecnológica avançada silenciosa oculta.

## 💻 Instalação Global Automática e Ativação Rápida Tática Oficial

### 1. Requisitos de Infraestrutura Operacional: 
Você necessitará apenas que o Hypervisor Mestre (o ecossistema **Docker** global junto com o **Docker-Compose**) esteja enraizado e rodando de prato no Windows do seu servidor de Treinamento ativo.

### 2. Levantamento e Compilação das Forças Armadas Táticas Militares:
Acesse a aba central root (raiz local) das instâncias virtuais encapsuladas e jogue o pacote em compilação na memória:
```bash
docker-compose down
docker-compose up -d --build
```
*Após disparar as chamas, os compiladores internos erguerão 3 Containers Isolados amarrados juntos via Roteamentos Nativos, e os servidores Gunicorn com UVICORNS assumirão todas as conexões TCP das docas simultaneamente em rede nativa estritamente isolada e auto-orquestrada operante segura criptográfica do Sandbox Lógico da base Tática Computacional*.

### 3. Assuma o Controle Via Monitor Primário Visual Cibernético Físico Superior:
Assim que os pacotes confirmarem as rotas, dirija um interceptador visual tático atualizado (Navegador Chrome ou EDGE compatíveis com CSS Avançado Gráfico Operante do Sistema GUI Diamond Military Design) na porta 8080:
**`http://localhost:8080`**
