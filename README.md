# 🛡️ XDR Neo-Platform | Enterprise Security Lab

**Plataforma unificada de Extended Detection and Response (XDR)**

Laboratório de segurança ofensiva e defensiva com algoritmos reais de detecção, resposta e inteligência cibernética. Ambiente isolado via microserviços com Docker Compose.

## Principais Capacidades

- Extended Detection and Response (XDR)
- SAST (Análise Estática de Código)
- DAST (Testes Dinâmicos)
- Auditoria Cloud / Kubernetes
- Detecção de DNS Tunneling
- Detecção de Anomalias (Z-Score)
- RASP (Proteção em Runtime)
- Attack Path Mapper (estilo BloodHound)
- Hash Cracker
- WAF + Simulador de Ataques

## Como Executar

```bash
git clone https://github.com/EriveltonRocha77/-XDR-Platform-Enterprise-Security-Lab-.git
cd "-XDR-Platform-Enterprise-Security-Lab-/landingpage erivelton/sec-analyzers-lab"
docker-compose up -d --build
```

- Interface: http://localhost:8080
- API: http://localhost:8000
